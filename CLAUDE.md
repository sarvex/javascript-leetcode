# CLAUDE.md - JavaScript LeetCode Solutions Guide

## Repository Structure
- Each file is named according to the LeetCode problem: `{problem_number}.{problem_name}.js`
- Solutions are implemented as standalone JavaScript files

## Code Style Guidelines
- Use JSDoc comments for function parameters and return values
- Prefer const for variable declarations when possible
- Use arrow functions for callbacks
- Use descriptive variable names (i for indices is acceptable)
- Employ modern JavaScript features (optional chaining, destructuring)
- Indentation: 4 spaces
- Semicolons at end of statements
- Prefer Map/Set for efficient lookups
- Use camelCase for variable/function names

## Solution Structure
- Include problem definition in JSDoc comments
- Optimize solutions for time/space complexity
- Add example usage in comments where helpful
- Handle edge cases appropriately

## Testing
- Solutions can be tested directly on LeetCode platform
- For local testing, use Node.js: `node filename.js`
